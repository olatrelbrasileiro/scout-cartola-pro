# Fundação ML futura

O laboratório ML legado foi removido nesta etapa. A próxima implementação deve manter uma fronteira explícita entre coleta Cartola, históricos, features, modelos de disponibilidade/minutos, expected points, optimizer e explicações por IA.

Nenhum modelo novo, optimizer, fonte externa ou feature parcial é implementado neste commit. O contrato histórico compartilhado está em `src/lib/data/` e o contrato canônico de scouts está em `src/lib/cartola/scouts.ts`.

A documentação do laboratório encerrado está em [`docs/ml-legacy-archive.md`](../../docs/ml-legacy-archive.md).
